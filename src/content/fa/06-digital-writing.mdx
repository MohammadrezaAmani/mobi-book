# نوشتن در عصر دیجیتال

برای نوشتن یک کتاب عالی، نباید با ابزار نوشتن بجنگیم. بهتر است قالب محتوا ساده و خروجی آن انعطاف‌پذیر باشد.

<Callout type="tip" title="مزیت متن ساده">
  یک فایل Markdown را می‌توان با هر ویرایشگر متنی باز کرد. محتوا به محصول یا
  سرویس خاصی وابسته نیست.
</Callout>

## یک سند ساده

```markdown
# عنوان فصل

این یک **پاراگراف مهم** است.

- مورد اول
- مورد دوم

![توضیح تصویر](images/example.webp)
```

## از متن تا تجربهٔ تعاملی

MDX این امکان را می‌دهد که کنار متن، کامپوننت‌های React هم داشته باشیم. همین فصل نمونه‌ای از MDX است.

<Quote attribution="دفترچهٔ Mobi">
  محتوا باید متعلق به نویسنده باشد؛ نه به ابزار نمایش آن.
</Quote>

## نسخه‌پذیری و همکاری

تغییرات کتاب در Git ذخیره می‌شوند. می‌توان اصلاحات را مرور کرد، با Pull Request پیشنهاد دریافت کرد و هر نسخه را دوباره منتشر کرد.
