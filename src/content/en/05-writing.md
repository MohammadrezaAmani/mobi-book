# Writing in the open

Text should belong to its author. A book composed of ordinary Markdown files is portable, reviewable, and easy to preserve.

## A small document

```markdown
# A chapter

This is **important** text.

- Write
- Revise
- Publish
```

With a GitHub repository and a static publishing workflow, your book can be online without a database or an application server.
